Project J.A.R.V.I.S.

J.A.R.V.I.S. est un assistant domestique inspiré d'IRON MAN, pensé pour Linux (GNOME). Un LLM local tourne via Ollama, appelle des outils (tool calling) pour piloter l'ordinateur, puis répond à voix haute avec Piper TTS. Rien n'est envoyé dans le cloud, hors météo et IP publique.

Python Ollama & ChromaDB Piper TTS
